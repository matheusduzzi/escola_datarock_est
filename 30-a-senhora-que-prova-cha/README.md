# 30. A senhora que prova chá

Os arquivos da aula «A senhora que prova chá» do curso Estatística para decisão.

## O que tem nessa pasta

| Arquivo | Para quê |
|---|---|
| `respostas-modelo.md` | A folha do exercício do teste das caixas. Salve uma cópia com o seu nome |

Essa aula não usa arquivo de dados. As camisetas da aula e as caixas do exercício são listas que você escreve no próprio código.

## Como rodar

Os blocos de código da aula rodam no Python aberto dentro dessa pasta:

```bash
python3
```

Depois cole os blocos da aula na ordem, a partir da seção 5. O bloco da seção 6 cria as funções `distribuicao_exata` e `chance_de_ou_mais`, e o da seção 7 cria a `simular`. O resto da aula e o exercício usam as três. Só a biblioteca padrão do Python é usada, sem instalar nada.

Os sorteios saem iguais toda vez que você roda. Se a sua saída tiver outros números, rode o bloco inteiro de novo, desde a linha do `random.Random`. Rodar só uma parte continua o sorteio de onde ele parou.

No Windows, troque `python3` por `py`.

Se precisar de ajuda, deixe um comentário na aula. Conte o objetivo, o comando que você rodou, a saída que apareceu e o que já tentou, sem dados pessoais.
