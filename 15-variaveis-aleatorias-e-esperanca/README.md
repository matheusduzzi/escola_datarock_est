# 15. Variáveis aleatórias e esperança

Os arquivos da aula «Variáveis aleatórias e esperança» do curso Estatística para decisão.

## O que tem nessa pasta

| Arquivo | Para quê |
|---|---|
| `respostas-modelo.md` | A folha do exercício, com um espaço por tarefa. Salve uma cópia com o seu nome |

A aula e o exercício não usam arquivo de dados. A contagem dos itens devolvidos em outubro e as duas tabelas de perda do crediário estão no texto. Os blocos de código montam cada distribuição como um dicionário.

## Como rodar

Os blocos de código da aula rodam no Python aberto dentro dessa pasta:

```bash
python3
```

Depois cole os blocos da aula na ordem, a partir da seção 4. O primeiro bloco cria o `dist`, e os outros usam ele. O sorteio da seção 7 usa só a biblioteca padrão do Python e leva alguns segundos. O bloco da seção 11 usa o pandas que o README do kit já instala.

O sorteio da seção 7 sai igual toda vez que você roda. Se a sua saída tiver outros números, rode o bloco inteiro de novo, desde o `import random`. Rodar só a linha dos `totais` continua o sorteio de onde ele parou.

No Windows, troque `python3` por `py`.

Se precisar de ajuda, deixe um comentário na aula. Conte o objetivo, o comando que você rodou, a saída que apareceu e o que já tentou, sem dados pessoais.
